    # governance

    Suite G — Governance, Grievance & Compliance

    Grouping folder only. Each sub-folder is an independent, portable module.
    This folder has no code of its own and no shared code between its modules.

    | Module | Description |
    |---|---|
    | [grievance](grievance/) | SGRC, anti-ragging and POSH-ICC complaint intake and resolution. |
| [rti](rti/) | RTI request intake, assignment, tracking and responses. |
| [iqac-accreditation](iqac-accreditation/) | IQAC data collection, NAAC/NBA metrics, evidence repository. |
| [regulatory-reports](regulatory-reports/) | UGC, AISHE, NIRF and other statutory reporting. |
