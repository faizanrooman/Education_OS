    # support

    Global Support Systems

    Grouping folder only. Each sub-folder is an independent, portable module.
    This folder has no code of its own and no shared code between its modules.

    | Module | Description |
    |---|---|
    | [helpdesk](helpdesk/) | Ticketing for all user roles with categories and routing. |
| [sla-management](sla-management/) | SLA definitions, timers, escalation and breach tracking. |
| [knowledge-base](knowledge-base/) | Articles, FAQs and how-to guides for self-service. |
| [incident-management](incident-management/) | Incident and problem records, root cause analysis. |
| [amc-vendor-support](amc-vendor-support/) | AMC contracts, vendor support engagements, renewals. |
