    # finance-operations

    Suite E — Finance & Institutional Operations

    Grouping folder only. Each sub-folder is an independent, portable module.
    This folder has no code of its own and no shared code between its modules.

    | Module | Description |
    |---|---|
    | [fees-accounts](fees-accounts/) | Fee structures, invoices, online payments, receipts, ledgers. |
| [budget-grants](budget-grants/) | Budget planning, grant tracking, utilisation certificates. |
| [procurement](procurement/) | Indents, tenders, purchase orders, vendor management. |
| [hr-payroll](hr-payroll/) | Employee master, leave, payroll, appraisals, service records. |
| [e-office](e-office/) | File movement, notings, approvals, digital correspondence. |
