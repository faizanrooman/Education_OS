    # student-lifecycle

    Suite A — Pre-Admission, Web Presence & Student Information

    Grouping folder only. Each sub-folder is an independent, portable module.
    This folder has no code of its own and no shared code between its modules.

    | Module | Description |
    |---|---|
    | [web-portal-cms](web-portal-cms/) | Public website, CMS pages, announcements, news and notices. |
| [admissions](admissions/) | Online application, document verification, merit lists, counselling and offers. |
| [student-information](student-information/) | Student master record (SIS): profiles, documents, ID cards, status history. |
| [enrolment-registration](enrolment-registration/) | Programme enrolment, semester registration, section and elective allocation. |
