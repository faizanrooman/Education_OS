    # campus-life

    Suite F — Campus Life & Student Services

    Grouping folder only. Each sub-folder is an independent, portable module.
    This folder has no code of its own and no shared code between its modules.

    | Module | Description |
    |---|---|
    | [hostel](hostel/) | Room allocation, mess, visitors, discipline and fee linkage. |
| [transport](transport/) | Routes, vehicles, passes, driver management, tracking. |
| [library](library/) | Catalogue, circulation, digital library, fines, reservations. |
| [placement-career](placement-career/) | Placement drives, companies, applications, offers, career services. |
| [alumni](alumni/) | Alumni directory, events, donations, engagement campaigns. |
