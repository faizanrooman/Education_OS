# sports

Suite C — Sports & Athletic Performance (custom domain)

Grouping folder only. Each sub-folder is an independent, portable module.
This folder has no code of its own and no shared code between its modules.

| Module | Description |
|---|---|
| [athlete-performance](athlete-performance/) | Athlete profiles, performance metrics, fitness testing, benchmarks. |
| [training-video-analysis](training-video-analysis/) | Training plans, sessions, video upload, tagging and annotation. |
| [sports-nutrition-health](sports-nutrition-health/) | Diet plans, medical records, injury tracking, physio sessions. |
| [tournament-events](tournament-events/) | Tournaments, fixtures, results, officials and event logistics. |
