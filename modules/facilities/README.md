    # facilities

    Suite D — Facility & Resource Management

    Grouping folder only. Each sub-folder is an independent, portable module.
    This folder has no code of its own and no shared code between its modules.

    | Module | Description |
    |---|---|
    | [sports-facilities](sports-facilities/) | Registry of grounds, courts, pools, gyms and their usage. |
| [facility-booking](facility-booking/) | Booking calendar for classrooms, halls and venues with approvals. |
| [inventory-equipment](inventory-equipment/) | Stock, issue/return, consumables and sports equipment lifecycle. |
| [asset-management](asset-management/) | Fixed asset register, tagging, depreciation, disposal. |
| [maintenance](maintenance/) | Work orders, preventive maintenance schedules, vendor tickets. |
